# IrunaDB v3.0.78 引き継ぎ

2026-10-21。

## タスクだけを別PCへ移す

タスク画面下部に「別のPCへタスクを移す」を追加。タスク専用JSONを書き出し、別PCで選択して内容確認後にタスク全体を入れ替える。タスク名・グループ・キャラ・曜日・時刻・塔・メモ・関連イベント名・現在数・目標・ペース・達成履歴を含む。削除済みタスクの履歴も保持。ビルド・装備・その他のlocalStorage値は移さない。

書き出しは未保存の個数/ペースも適用したコピーを含める（元PCの保存値は変更しない）。編集中で未登録のタスクは含まないことを画面に明記。

ファイルはformat IrunaDB-tasks/schemaVersion1/appVersion/createdAt/data。タスクの既存保存スキーマ1を維持、旧任意フィールドなしのデータ・空配列も対応。既知のタスク/履歴フィールドだけを扱い、関係ない値を除外。20MB上限。形式不正/重複ID/不正値/異常日付などは既存モデルで検証し、確認前や失敗時に元のタスクを変更しない。

取り込み直前のキーirunadb.tasks.v1の生文字列（または未存在null）をirunadb.tasks.beforeImport.v1へ保存してから置換。バックアップ作成に失敗したら置換しない。置換保存が失敗した場合も元値を保持。取り込み前へ戻す機能は画面内確認を挟み、元の生文字列を正確に復元。取り込み前のバックアップは1回分。バックアップキーは環境の共有対象に含めない。

取り込み/復元時は現在のフォームと未保存下書きを破棄することを画面に明記。自動同期ではなく、ファイルを手動で別PCへ渡す。
