# v3.0.55 生産・ドロップ情報

## 追加内容

- 「生産」「ドロップ情報」タブ。登録済み3レシピ、7アイテム、3ドロップを収録。
- 分野別の生産Lv（1人分）、Lv条件を満たすレシピの絞り込み（自分の同分野のLv＋10まで）。必要道具は別途表示。
- 生産レシピのお気に入り、お気に入りのみ表示、上下ボタンによる並べ替え。
- レシピ名・必要素材による検索、モンスター・マップ・アイテム名による入手先検索。
- レシピ→素材詳細→入手先、素材詳細→使用レシピ、完成品詳細→生産方法の移動。
- 素材・収集品・消費アイテムをDBへ表示。ビルド候補には追加しない。
- 通常・大成功A・大成功Bを分け、出典・確認日・未検証事項・不明なドロップ率を表示。

## データの扱い

`data/catalog.js`は接続済みGoogleスプレッドシートの確認済み範囲から作成したスナップショットです。公開ページから非公開スプレッドシートを直接読む構成ではありません。スプレッドシート更新時には、参照IDと出典を検証したうえでスナップショットを更新します。今回、自動同期は実装していません。

既存DBとIDを照合し、追加アイテムをDBへ結合します。既存アイテムIDの変更やdata/db.jsonの置換は行いません。装備品とは分類を分け、既存のビルド保存や装備箇所判定を維持します。

現在の初期レシピ：つるはし（鍛冶Lv4）、ゆで卵（調理Lv2）、黒焼き（調理Lv7）。モンスターのLv・属性に現行ゲーム内未確認の項目があるため、資料の確認状態を残しています。

## ユーザー設定

新規キー`irunadb.craft.user.v1`に生産Lvとお気に入りID配列を保存します。配列順が生産ルートの表示順です。保存失敗時は画面に通知し、保存済み設定を維持します。

環境エクスポート・インポートと自動バックアップ／ロールバックの対象に追加しました。取り込みファイルにこのキーがなければ、既存設定を保持します。キーがある場合はファイルの内容で上書きします。旧バージョンでは新しいキーを受け付けないため、新しい環境JSONはv3.0.55同士で共有してください。
