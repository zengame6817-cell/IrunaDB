# IrunaDB v3.0.75 引き継ぎ

2026-10-18。

## タスク機能

メニューにタスクを追加。自由な追加・編集・削除、グループ・キャラ・メモ・表示曜日・表示時刻・毎日/毎週/1回だけを設定できる。初期タスクは土日だけ表示する闇の結晶イベント。水やり、収穫、ペットの餌やり、イグナイト、妄世の塔、土日のイベントは入力ひな形。時刻は表示のみで通知なし。ユーザーの別チャット「タスクを整理」を画面構成の参考にし、個人の実績・所持数は公開コードへ入れていない。

毎日のチェックは日本時間0時、毎週は月曜0時に期間キーで切り替える。前日に達成したタスク名・キャラを上部表示。累計達成回数は設けず、各タスクの現在数・目標数・残数を表示。現在数は日付が変わっても保持し、ユーザーが更新する。削除後も過去の達成記録は保持。チェック戻し・履歴リセット・個数リセットは別操作で確認表示を挟む。

関連イベントを選択でき、登録データに該当イベントがあれば期間・公式情報へのリンクを表示。同名イベントは今後の直近回を参照。通知・スマホカレンダー登録はユーザー希望で未実装。アプリ化は別途。

端末保存キーirunadb.tasks.v1。タスク最大500、履歴最大50000。保存・検証エラー時は元の保存値を上書きしない。既存の環境JSON保存/取り込み/復元の対象にも追加。各端末のブラウザ内保存で、端末間自動同期はない。

## 検証と残作業

全58テスト成功。日本時間の日替わり、週/月/年境界、土日表示、チェック戻しと個数保持、不正値・重複履歴の拒否、環境保存への統合を検証。ローカル実画面で個数付きカスタムタスク追加、チェック、再読込後の完了・個数保存、テスト用タスクの削除を確認。

既存アイテム・スプシは変更なし。未解決アイテム68監査行などはv3.0.72を参照。カレンダー最新の自動更新は維持。
