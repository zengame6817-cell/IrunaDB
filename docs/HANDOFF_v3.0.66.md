# IrunaDB v3.0.66 引き継ぎ

2026-10-17。ユーザー希望により「ドロップ情報・入手先」を変更。

- マップ→エリア・階層を選ぶと、その区画に登録されたモンスターを表示。マップ名が同じ区画はエリア選択で切り替え、モンスターID・Lvの異なる個体は保持する。
- 各モンスターに第1～第4ドロップを表示し、登録済みのアイテム詳細へリンク。モンスター名から詳細・出現場所へ移動できる。
- 既存DROP_MASTER相当データの枠番号確認済みは3行（第1が2行、第3が1行）。それ以外11,401行は空欄。枠不明のアイテムを件数順やID順で第1～第4へ振り分けず、「枠未確認」にリンクを表示する。未確認の枠は「未確認」。追加調査が必要。
- ドロップカードとモンスター・マップ詳細から確認日、確認状態、調査用備考を非表示。モンスター詳細の難易度表示とマップの資料区分等の説明も削除。実際の条件は通常のドロップカードに保持。スプシ・元データ・出典・確認記録は削除しない。
- マップ／モンスター詳細では同じドロップカードを下に重複表示しない。種別・ドロップ区分フィルターは全体検索で表示し、マップ／モンスター詳細では隠す。

能力・条件・ID・スプシの変更なし。v3.0.65の参照用122件、Wiki保留599項目、未照合ドロップ131件は継続。次はモンスター個別資料でドロップ枠順を確認して埋める。資料の単なる配列順から枠番号を断定しない。

検証：マップ／エリア切替、同名別Lv個体の分離、第1・第4枠と枠未確認のリンク、不要な調査表示の非表示をテスト。テスト33件成功。ローカル実画面でロココ鉱山の村のモンスターと第1～第4表示、まがったピッケルへのリンク動作を確認。公開確認は完了後に記録する。
