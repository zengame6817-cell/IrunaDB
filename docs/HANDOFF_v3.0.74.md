# IrunaDB v3.0.74 引き継ぎ

2026-10-18。

## 変更

カレンダーの月表示の上部に月間イベント一覧を追加。同名イベントを一つにまとめ、同月内の登録が複数ある場合は回数を表示する。月をまたぐイベントも対象。月移動・検索・分類の絞り込みに連動し、イベント名を押すとその月の詳細一覧を表示して該当イベントを開く。日別表示と今日の黄色強調は維持。

生産カードから必要道具の行、確認日・確認状態の監査行、指定された品質強化説明、大成功の未記載・ゲーム内未検証の注意文を非表示にした。元の出典・レシピデータ、材料・完成品・Lv条件、その他の備考は保持。スプシ変更なし。

## 検証

月間一覧の同名集計・月境界をテスト。全54テスト成功。ローカル実画面で10月32種類の一覧、名前からハロウィンの詳細を開く動作、生産カードで指定文がなく材料・完成品があることを確認。GitHub最新の自動更新calendar.jsonを保持。

## 残作業

未解決アイテム68監査行や武器計算対応はv3.0.72、カレンダー日別表示はv3.0.73を参照。
