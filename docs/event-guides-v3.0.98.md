# イベント攻略・入手アイテム拡充

10種類・45攻略・151件の入手情報。ユーザーの希望に従い、イベント画面からブログ名・外部リンク・確認日を除去。検証資料は開発用の evidence JSON と攻略データの source に残す。画像は確認のみに使用し、他サイトの画像をアプリへ転載しない。

追加カテゴリはイースター・剣豪・クリスマス・ディストラクション・ジーン・学園・アニバーサリー・人魚。ハロウィン2021〜2026、バレンタイン2018・2019・2025・2026、ホワイトデー2026、人魚1〜9話を追加。攻略は要点の短い案内で、全イベント・全年度・全アイテムを網羅したものではない。学園はグッバイ、ドリームスクールを初期登録。アニバーサリーは闘技会・レイドの周回導線を登録。

## 照合時の判断

- ホワイトデー2026：大福記事はスイーツ／ジュエルの報酬がケン記事と逆。ケン記事のゲーム画像に「ホワイトスイーツを1個渡し 恋慕の首飾りを1個貰いました！」の表示があり、画像を優先。対応はスイーツ→首飾り、ジュエル→クッフィアロリタ、コート→プリンチカペロ。後二者は本文照合であり全組合せの画像確認ではない。
- 学園：大福記事にコトネロ・空絵事の表記があるが、えーへい・Wikiではタピコラ・絵空事。複数資料の一致を採用。装備の枠順は資料間で異なるため記載しない。Lv50でもクリスタ、体・追加装備はLv400側と区別。
- ハロウィン2023：ジャックハンマーと首飾りのドロップ順に不確かさがあるため枠順を表示しない。かぼちゃケーキはケン記事のゲーム画像でも名称を確認。
- イースター：大福記事の「転廻の欠片」に対して、えーへい・別攻略ブログ・Wikiでは「輪廻の欠片」。輪廻を採用。生命の卵（拾うクエスト対象）と生命の生卵（通常ドロップ）は区別。
- ディストラクション・ジーン：大福の攻略によりEP1クリア条件とバイルーンのバルナを補正。ユルの再戦レベル・最初の2品の順序が資料間で異なるため入手表ではレベル・枠順を断定しない。
- チクスイの森の通常Wikiはイベント版と違うモンスター表のため、剣豪の報酬根拠には使用しない。
- ホワイトデー2023の開始条件は公式2026告知に合わせ「シュガー・メディシン」クリアを明記。
