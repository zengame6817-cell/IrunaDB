# IrunaDB v3.0.92 — 鍛冶屋専用タブ（2026-11-03）

## 要望
- 鍛冶屋を生産の内部ではなく、独立したナビゲーションタブへ。
- 「強化」が分かりにくいので、強化元 → 強化後の関係を最優先で見せる。
- 既存80件・素材・費用・装備詳細からのリンクを維持し、GitHub Pages向けキャッシュを更新。

## 実装
- index.html: メニューに鍛冶屋タブを追加、view-forgeの独立画面を新設。生産から古い折りたたみパネルを撤去。
- js/catalog.js: 鍛冶屋カードの中心に強化元 → 強化後を並べ、作成レシピは「鍛冶屋で作成」と区別。装備強化／装備作成の種別選択、町、検索、クリア、30件ずつ表示。素材は展開式。装備詳細やドロップから開くリンクはforgeタブへ。
- css/catalog.css: 新しいカードとスマホ向けの見た目。
- js/config-v3.0.92.js, index.html, service-worker.js: v3.0.92に更新してキャッシュ切替。
- 出典情報、素材、費用、forge.jsは変更なし。個人ブログの本文・画像・記事URLを転載しない方針を維持。
