# v3.0.60 モンスター・マップの詳細と素材の入手先

生産の素材から入手先を開き、モンスター名からその個体の詳細・ドロップ、マップ名からその場所の登録済みモンスター・ドロップへ移動できます。「戻る」で検索語・表示件数・スクロール位置を復元します。同名でもLv・場所・ドロップが異なる個体はIDで区別します。アイテム詳細・生産レシピへの既存の移動も維持します。

入手先一覧は50件ずつ表示します。検索は全登録分を対象とし、追加表示後は新しい先頭カードへ移動します。登録のない情報は「未登録」と表示し、ドロップしないと断定しません。

## 登録範囲

2026-10-16に、既存レシピで使用頻度の高い素材32種と初期素材8種の計40アイテムページを確認しました。参照元は https://jp.iruna-online.info/iruna/item/ 以下の日本語資料です。通常エリアの資料区分EP1～6に絞り、期間限定・他区分・日本語マップ名が照合できない記載を除外しました。40素材中22素材についてドロップ先を登録しました。同じ個体に併記されたドロップも、既存のアイテムIDと名前が一意に対応する場合だけ登録しています。

合計：マップ363件（区画違いを含む）、モンスター547件（場所・Lv・ドロップ差を含む）、出現547件、ドロップ1,804件。追加は順に360・545・545・1,801件です。すべてのマップ・全モンスター・全ドロップを網羅するものではありません。資料の転記確認であり、ゲーム内の最新仕様は未検証です。未照合のアイテム名は自動生成しません。

連続するLvでも、マップ・区画・属性・弱点・攻撃性・全ドロップ品名が同じ場合だけLv範囲にまとめます。飛び番は別個体です。枠番号、確率、難易度別条件は推測せず空欄とし、アプリでは未確認と表示します。追加分の種別も不明のため空欄です。

旧登録のレーデ塩湖にはEP2、今回資料にはEP1の表記差があったためエピソードを空欄にして要確認としました。ダズルの旧Lv113～114は今回資料のLv113個体と分け、Lv116も別IDで登録しました。旧値と変更理由は注記・coverageに残しています。

## データとスプレッドシート

既存スプレッドシートのMAP_MASTER・MONSTER_MASTER・MONSTER_SPAWN・DROP_MASTERを更新し、SOURCE_MASTERのSRC000021に取得範囲を記録しました。全3,262行の書き込み値を読み戻し照合しました。既存IDを維持し、ヘッダー・既存の書式・他のシートは保持しています。

アプリはdata/catalog.jsにdata/locations.jsの補足スナップショットを検証して統合します。追加データの重複ID・欠落参照・不正Lv・既存名の別名置換は失敗として扱います。data/location-coverage.jsonに集計、除外数、未照合名、旧値と変更、参照40ページのSHA-256を保存しています。21アイテムはdata/db.json内の既存レコードを参照用にコピーしています。装備の数値は追加・変更していません。

将来MAP等をdata/catalog.js本体へ取り込む場合は、同じIDを補足ファイルから除いて二重登録を避けてください。スプレッドシートからアプリへの自動同期はまだありません。外部出典URLは管理データに保持し、アプリには表示しません。

バージョン表示・SWキャッシュ名はjs/config-v3.0.60.jsのAPP_VERSIONを参照します。HTML/SWへ補足データと画面モジュールを追加しました。data/db.json、レシピ、ビルド、保存設定・保存キーは変更していません。
