## 確認した資料と原因
- 日本語WikiのSPコーダル：基本オート+3%、体追加+3%。追加に付けた場合はクリダメ+6%。
- スプシ EFFECT_MASTER、CR000045：CREFF000125/126 基本、CREFF000127/128 旧条件、CREFF001551/1552 後追加条件。同じ「体装備時+3%」「追加装備時クリダメ+6%」が別の条件グループで二重登録。CONDITION_MASTER CRCG000030とCRCG000217はいずれも体装備。
- ☆生命力Lv1〜5 のマスタを ST000091〜ST000095 として確認。日本語Wiki ☆能力の注意点も確認。
