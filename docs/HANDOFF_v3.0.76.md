# IrunaDB v3.0.76 引き継ぎ

2026-10-19。

## タスク画面

グループ内を画面幅に応じた複数列カードへ変更。最小カード幅280pxを基準に自動折り返し、狭い画面は1列。名前・キャラ・曜日・時刻・完了・編集/削除を維持し、余白を縮小。

個数管理に1日平均ペース（pace）を追加。現在数・目標数・ペースから ceil(max(0,目標−現在数)/ペース) で達成まで約何日かを表示。休みの日も含む平均ペースによる暦日換算で、表示曜日だけの日数ではない。目標達成済みは「目標達成！」。目標なし/ペース空欄/0は日数を計算しない。整数個数、有限の0～999999999のペース、小数ペースに対応。

追加/編集フォームとカード上でペースを設定。カードでは「個数・ペースを保存」でまとめて確定する。旧タスク保存キー・スキーマ1を維持し、pace未設定の旧データを読み込める。破壊的な移行や保存値の一括書き換えなし。完了記録・曜日・個数・環境保存/取り込みを維持。通知なし。
