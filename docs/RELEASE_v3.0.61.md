主な参照元を https://irunawiki.com/ja_JP にして、クリスタ・装備・素材・消費など19分類ページの7,535項目と、サイト自身が表示に使う公開モンスター一覧3,706個体を確認しました。日本語名がない項目は除外し、英語説明しかない5件の説明も採用していません。対象版や最新仕様が保証されたデータとして扱うものではありません。「確認日」は資料を取得・照合した日であり、更新日やゲーム内検証日ではありません。

## 追加と照合

既存5,029アイテムを日本語名・分類で一意に照合しました。全角半角・空白・先頭のクリスタ記号だけを正規化し、名前の類似や強化版番号からの推測はしません。同じ既存IDに複数の出典アイテムが対応する場合も保留しました。ID候補が複数、強化段階が未照合、期限付き能力などの617項目は新規能力の自動登録から除外しています。

1,254アイテムを新規登録しました。主に素材・消費・スキル習得用アイテムで、通常の装備や条件付きクリスタの不足数値を補完していません。日本語説明が単純な率加算だけのクリスタ3件についてのみ「絶対回避+1%」「絶対回避+2%」「クリティカル率+5%」を追加能力として登録しました。その他の既存能力・条件・ATK/DEF・レリック形状は変更していません。

ドロップ9,584件を追加し、既存1,162件の出典を再照合しました。登録合計はドロップ11,388件・モンスター3,217件・出現3,425件・マップ624件です。同名でも場所・Lv・区画・種別・ドロップが異なる個体を分けています。ボスと明記された資料からは、クリスタ194種類・入手先の組み合わせ229件を確認できます。資料で種別が不明な個体を推測でボスにはしません。

確率・枠番号・難易度別条件は推測せず未確認です。日本語の区画名が未照合の場合は、英語の区画名を新規表示せず、日本語名のマップ単位で登録しています。イベントは過去の掲載情報として区別し、現在開催中とは扱いません。日本語のないアイテムや未照合ドロップは落とさないという意味ではありません。全データの完全網羅は保証していません。

## 画面

入手先に「モンスター種別」「ドロップ区分」を追加しました。「ボス」と「クリスタ」で絞り込めます。検索・フィルターは全登録分に適用し、50件ずつ表示します。詳細へ進むとフィルターを解除して対象を表示し、戻ると検索・フィルター・表示件数を復元します。検索用の出現情報を索引化し、大量のドロップごとに全出現一覧を走査しないようにしました。

アイテム詳細の「資料の照合（日本語）」で出典の説明やATK/DEFの資料差を確認できます。説明の表記差は数値の誤りと断定せず、既存の計算値を保持します。既存説明が空欄・名称参照用の仮文言の場合だけ日本語説明を補完し、具体的な既存説明を置き換えません。資料の説明は効能検索にも使用します。アプリに外部出典リンクは付けていません。
