新規js/november-calculation.jsでID・名称・分類・画像照合済み説明文の組を限定して登録。既存効果は保持し、同じ効果の再読み込みは冪等、同じIDの異なる効果は拒否。js/wiki-data.jsの閲覧専用判定はこの6点だけ解除。ほかの未検証装備や収集品は従来どおり。

アプリの実データ読込経路にlatest-itemsを追加。以前はカタログ補足としてのみ読み込んでいたため、ビルドの索引へ届かなかった問題も修正。API取得・静的DB取得の両方で同じ補足と効果を適用し、db.jsonやスプレッドシートは変更しない。

氷晶のブローチの魔法追撃、レジストハイドの確率軽減は発動率・威力・軽減量が未確定。数値を捏造せず、選択中だけ合計欄に「未計算」と表示する。特殊・追加装備の個体DEFも未計算と表示。画像の個体スロットやDEFを固定仕様にしない。サフィエクラルのATK上限不一致も元の注意書きを保持。

これは既存シミュレーターの能力加算への対応であり、最終キャラクターATK/MATKや攻撃ダメージ・確率発動の期待値を新たに計算するものではない。DEX/VITも他の既存固定効果と同じ合計欄へ加算する。通常の保存・URL共有は既存のアイテムID形式を使用。
