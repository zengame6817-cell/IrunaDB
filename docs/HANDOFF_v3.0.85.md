## スキル・MSからDBへ移動

素材名・スキル本はアイテム詳細（入手先へのボタン付き）、モンスター名は出現場所・ドロップ、場所名はそのマップ一覧へ移動する。対象は有効な登録名との完全一致で、文章内では語の境界と最長名を使う。◇・◆・▲は区別する。素材/討伐/場所の文脈で種類を絞る。NPCだけの名前は場所欄からモンスターへ結び付けない。

同名候補は勝手に一件へ決めず、分類・ID、Lv・マップを表示して選択。例：記憶の欠片はRL000212（レリック）とIW00006747（素材）を別候補にする。ゴーストも既存のLv/場所別個体を保持。未登録名・表記違いはリンクしない。旧資料の「モンゴレ地下廊」などは推測で別マップへ置換しない。

ドロップ画面に「スキルに戻る / MSに戻る」を追加。検索・職業・開いた習得条件を保持して戻る。名称ボタンはMS素材の所持チェックを変更しない。

実装：js/reference-links-model.js、js/reference-links.js、css/references.css、既存skill-quests/missions/catalogから接続。

data/skill-supplement-v3.0.85.jsをdata/skills.js直後に読み込む。既存データを変更せず補足を統合し、二重適用しない。Googleスプレッドシートのスキル表・data/skills.js本体は今回変更していない。再生成時にもこの補足の読み込みを残すこと。

- パラディンにナイトから引き継ぐウォークライLv1/Lv2を追加（PALSK000011/12）。Lv1 ATK・MaxHP各+8%、2分。Lv2各+12%、3分。日本語Wiki資料確認。初期OFF、Lvを選択してONの間だけ反映。

- 効果ID JPSE085001～005。既存のグラディエーター/ビーストナイトのウォークライLv3などは変更しない。ビルドの既存集計は増加率の合計であり、実HP値の算出式は追加していない。

## 外部リンクの方針（利用者指定）

画面に表示する外部資料リンクはWikiと公式のみ。スキル効果の出典はIrunaUtils.isPublicSourceUrlで許可されたドメイン/パスに限定。既存のirnsnk.comや今回の個人検証ブログはリンクを表示しない。資料URLは照合記録としてデータ/本メモに残す。カレンダー/タスクのリンクは既存の公式URL限定検証を通ったデータ。グランドクルセイドの参考値をWiki確認済みと扱わない。
