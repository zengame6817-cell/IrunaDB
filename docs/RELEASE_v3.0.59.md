# v3.0.59 生産の並び替え・絞り込みと効能検索

レシピを50件ずつ表示するボタンが、カードと同じ高さまで伸びて大きな空白に見える問題を修正しました。続きの操作を横一段に分け、該当件数・登録件数・表示中の件数を区別します。追加表示後は新しい先頭カードへ移動します。お気に入り追加や生産Lv保存で表示件数を最初の50件に戻さないようにしました。

生産にLv昇順/降順・名前順・分野順、完成品の区分（装備/回復/消費/素材・収集品/その他）、作成/強化、Lv範囲、効能の選択とキーワード検索を追加しました。検索と絞り込みは表示中の50件だけでなく全3,570件を対象とします。分類と効能は同じ完成品が条件を満たす場合に一致とし、大成功の完成品も対象です。お気に入りだけの表示はユーザーが保存した順序を優先します。

データベースにも同じアイテム区分と効能検索を追加しました。既存の分類タブ・能力ランキング・お気に入りも維持します。区分の変更時は分類タブとの意図しない競合を解除します。

回復・状態異常回復・一時強化・移動の日本語資料4ページから、既存の回復/消費アイテム448件すべての名前を照合し、説明を補完しました。同名異文の競合はありませんでした。説明からHP/MP回復、状態回復、攻撃、防御/耐性、ステータス、経験値、移動を検索できます。名前からの推測は行わず、効能が書かれていない紹介文は「効能の記載なし」で区別します。装備については既存の能力データも対象です。選択項目は説明文を用いた検索補助で、ゲーム内の効果を検証済みと扱うものではありません。

元スプレッドシートのITEM_MASTERで該当448件のD列（サブ分類）・O列（説明文）を更新し、書き戻しを照合しました。SOURCE_MASTERにSRC000020を追加しました。アプリではdata/item-effects.jsの補足スナップショットを既存IDに重ねます。既存の能力数値・ビルド・保存キー・data/db.jsonは変更していません。アプリに外部出典リンクは表示しません。

確認：12テスト（構文、参照、SW/HTML、データ整合性、HP/MP/MaxHPの区別、効能不明、環境保存等）。ブラウザーで1440/1000/720/390pxの段階表示ボタン、追加後のフォーカス、並び替え、Lv境界と不正範囲、区分・効能の組み合わせ、DB側検索解除、お気に入り・メモを確認。
