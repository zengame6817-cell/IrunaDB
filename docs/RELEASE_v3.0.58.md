## アイテムメモ

ヘッダーの「メモ」から名前の手入力・入手済みチェック・個別削除・チェック済み削除ができます。レシピの素材とアイテム詳細からも追加でき、同じ名前の重複追加を防ぎます。このブラウザーの localStorage irunadb.itemMemo.v1 に最大500件を保存します。既存キーは変更していません。読み込み・保存失敗は表示し、失敗した保存で画面や元データを置き換えません。環境JSONのエクスポート・インポート・自動バックアップ・復元にも含まれます。

一覧は50件ずつ表示し、素材・完成品の索引により検索時の全件走査を抑えています。
