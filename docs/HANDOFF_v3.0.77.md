# IrunaDB v3.0.77 引き継ぎ

2026-10-19。

## 妄世の塔

妄世の塔ひな形を選ぶと「挑戦する塔」の選択欄を表示。白日の閃塔・忘失の虚塔・絶息の氷塔・彷徨の影塔・試練の巌塔・使命の炎塔・因果の嵐塔の7択。既存タスクもタイトル/グループに妄世が含まれる場合、またはtower保存済みなら編集欄を表示。選択した塔はカードに表示。towerは任意フィールドで旧保存データとの互換を維持。既存メモは別フィールドとして保持し、自動上書きや旧メモの自動解析・変換はしない。

名前はユーザーの「タスクを整理」の参照情報を基に、白日の閃塔は公式https://android.iruna.jp/info?no=26985、絶息の氷塔は公式https://android.iruna.jp/info?no=12734で名称確認。報酬数・能力・必要個数の推定追加なし。

## 個数・ペースの一括保存

各カードに異なる現在数・ペースを入力し、一覧上の「個数・ペースをまとめて保存」でまとめて確定。各カードの保存ボタンは廃止。未保存件数を表示。入力は画面内の下書きMapに保持し、チェックや表示切り替え・定期再描画でも消さない。非表示のタスクの下書きもまとめて保存対象。画面再読込をまたぐ未保存入力の永続化はしない。

一括保存は複製に全件適用→全件検証→保存の順で、不正値を含むと一部だけ保存しない。旧個数・履歴・ペースと環境保存を維持。個数リセット、編集保存、削除時は対象の下書きを整理。

## 検証・残作業

全62テスト成功。7択、旧データ互換・メモ保持、各カード別ペース・一括保存の原子性を追加検証。ローカル実画面で白日の閃塔・忘失の虚塔を選択して保存、5個/日と7.5個/日を同時入力し、チェック後も下書き保持、一括保存後20日/14日表示、再読込後も保持を確認。確認用タスクは撮影後削除。

アイテム・スプシ変更なし。残作業はv3.0.72、タスクの基本はv3.0.75、ペース計算はv3.0.76を参照。
