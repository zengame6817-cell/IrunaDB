メニューに「モンスター」を追加。ユーザーは検索窓追加ではなく専用タブを希望。通常・ボス・レアモブ（マスター上のミニボス）・種別未確認を含む有効3,227個体、名前1,301種類を掲載。同名でもLv・場所等が異なる個体を統合しない。ドロップ登録の有無にかかわらず掲載。

## 属性照合

空欄53個体を調査。10/16採取済み一覧を候補探索に使い、同名・Lv範囲・同マップの候補48ページを10/23に実取得（HTTP 200、エラー0）。34ページに属性があるが同一対象の複数資料を含むため、補完対象は33個体。既存の非空欄属性は変更しない。同名・Lv・マップを満たさないもの、資料属性nullなど20個体は未確認のまま。

属性補完と照合URL・日付・個体条件はjs/monster-attributes.js。適用時にID・名前・上下限Lv・出現マップを全件検証してから空欄だけ補完。catalogの読み込みに適用する。data/db.jsonや能力値・条件・Lv・ドロップ率は変更なし。既存の属性変化表記（火→水等）は記載された各属性で一致するようにした。属性物理や耐性から属性を推定しない。装備の空欄属性については今回補完していない。
