# v3.0.56 日本版の生産レシピ追加

全6分野のLv1～20について、材料と通常完成個数を確認できた作成レシピを追加しました。登録レシピは3件から212件へ増加。別分野の生産Lv条件が未確認の「星の雫」4件を非表示とし、画面では208件を表示します。

| 分野 | 登録件数 | 表示件数 |
| --- | ---: | ---: |
| 鍛冶 | 31 | 29 |
| 木工 | 37 | 37 |
| 裁縫 | 34 | 34 |
| 彫金 | 29 | 29 |
| 錬金術 | 52 | 50 |
| 調理 | 29 | 29 |

同名でも分野・Lv・材料が違うレシピは別登録し、初期3レシピのIDを保持しています。素材行488件、完成品行344件を追加し、通常／大成功A／大成功Bを区別しました。出典に記載がない大成功は推測せず未登録としています。

スプレッドシートのITEM_MASTERには参照用アイテム263件を追加しました。既存の装備はIDを再利用し、同名・異なるIDの装備を自動統合しません。アプリのカタログには既存装備の参照データも含めますが、読み込み時は既存DBの装備を優先し、能力を上書きしません。新規素材・収集品・消費アイテムはビルド非対象です。

今回の参照元は、日本語サイトのうち日本版として区分された `productionsjp` ページです。通常レシピの材料と個数を抽出し、ID参照と重複を検査しました。ゲーム内での検証済みとは扱っていません。強化上限や条件が分からない強化レシピ、同名装備の対応を確定できないレシピは採用していません。Lv1～20の全レシピを網羅したとの保証ではありません。

別分野Lv条件が必要な「星の雫」はレシピ・素材・完成品を有効FALSEとし、必要条件の検証後に公開する予定です。既存のドロップ3件は保持しました。新規素材すべてのドロップ元を今回追加したものではありません。

ユーザーの希望により、アプリの「出典を確認」リンクと入手先欄の参照URL表示を取り除きました。確認日・確認状態は表示し、出典URLはスプレッドシートと検証用データに保持します。

データの整合性・Lv境界・お気に入り・環境設定・JS構文・SW参照の6テストを実施。ブラウザーでも208件の表示、素材検索、相互リンク、お気に入り順序、生産設定の環境JSON取り込み・復元、外部参照リンクの非表示とスマートフォン幅を確認しています。

今回もスプレッドシートの確認済みデータのスナップショットを更新しています。自動同期・イベント・ログインボーナス情報は後続対応です。
