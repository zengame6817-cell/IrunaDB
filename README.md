# IrunaDB

Iruna Online Database & Build Simulator

## Version

`v0.4.0`

## v0.4.0 実装内容

- 職業選択
- Lv / STR / INT / VIT / AGI / DEX / CRT入力
- CONDITION_MASTERによる条件判定
- 発動中・未発動の条件付き能力表示
- 発動中能力を合計値へ反映
- 装備とステータスの共有URL保存・復元
- 表示分類を優先表示
- サブ分類の重複表示を抑制
- JOB_MASTER API連携

## 更新方法

ZIPを解凍し、GitHubリポジトリへ全ファイルを上書きアップロードします。

## GAS

既存の `?action=jobs` を利用するため、GASの変更は不要です。
