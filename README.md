# IrunaDB

Iruna Online Database & Build Simulator

## Version

`v1.0.0`

## v1.0.0 主な変更

- 装備タブの選択済みアイテムをタップすると、データベースと同じ詳細画面を表示
- 装備変更は独立した「変更」ボタンから実行
- データベース詳細からタグ表示を削除（検索用データとしては維持）
- 装備選択画面でATK・DEF・属性・全能力・条件付き能力・説明文を省略せず表示
- 表示文に数値がない場合、能力ID・値・単位から自動補完
- レリック盤面を装備タブから非表示にし、行形式の一覧へ変更
- レリック行から詳細画面を表示可能
- 精錬UIを削除し、全装備を常時+9として扱う
- 武器属性の手動選択を廃止し、ITEM_MASTERの属性IDを自動参照
- v0.9.0までのスロット、条件判定、URL共有、レリック配置データを維持

## 更新方法

ZIPを解凍して、GitHubリポジトリの全ファイルを上書きしてください。

GASの変更は不要です。
