# IrunaDB

Iruna Online Database & Build Simulator

## Version

`v0.8.0`

## v0.8.0 実装内容

- 装備画面のHTML構造を全面再構成
- 装備、クリスタ、アルクリスタ、レリック、合計能力を一体型レイアウトへ統合
- PCでは左側に編集、右側に合計能力・共有を固定表示
- スマートフォンでは1列へ自動変更
- β5を意識した黒・金・シアン基調
- レリック盤面を専用フレーム化
- 下部固定ナビゲーション
- CSS・JavaScriptへバージョン番号を付与し、GitHub Pagesの古いキャッシュを回避
- v0.7.0までのデータ処理・レリック配置・条件判定・共有URL機能を維持

## 更新方法

ZIPを解凍し、GitHubリポジトリへ全ファイルを上書きしてください。

GASの変更は不要です。
