# IrunaDB

Iruna Online Database & Build Simulator

## Version

`v0.7.0`

## v0.7.0 実装内容

- `iruna-tools-beta5.html` を基準にしたUI統合
- 茶・金・シアン基調の配色
- コンパクトな装備行
- 装備ごとのクリスタ・☆能力を同じ構成で表示
- アルクリスタ横並び表示
- 下部固定ナビゲーション
- 合計能力を一覧性の高いグリッド表示
- データベース・モーダル・レリック盤面も同じデザインへ統一
- v0.6.0のレリック配置・条件判定・URL共有機能を維持

## 更新方法

ZIPを解凍し、GitHubリポジトリへ全ファイルを上書きしてください。

GASの変更は不要です。
