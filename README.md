# IrunaDB

Iruna Online Database & Build Simulator

## Version

`v0.6.0`

## v0.6.0 実装内容

- 5列×3行のレリック盤面
- `RELIC_PATTERN_MASTER` の座標データを利用
- レリック追加時の自動配置
- 0°・90°・180°・270°回転
- 反転なし
- 盤面外判定
- レリック同士の重なり判定
- 配置レリックの能力集計
- 配置状態の共有URL保存・復元
- v0.5.0の旧共有URLを可能な範囲で移行

## 対応する形状列名

次のいずれかを自動認識します。

- 配置
- 形状
- 座標
- パターン
- 座標データ
- cells
- pattern

値の形式:

```text
[[2,0],[1,1],[2,1],[3,1],[0,2],[1,2],[2,2],[3,2],[4,2]]
```

アイテムとの対応は、まず `アイテムID` を使用し、なければ `名前` または `レリック名` で照合します。

## 更新方法

ZIPを解凍し、GitHubリポジトリへ全ファイルを上書きしてください。GASは既存の `relicPatterns` APIを利用するため変更不要です。
