# IrunaDB

Iruna Online Database & Build Simulator

## Version

`v0.3.0`

## v0.3.0 実装内容

- 装備・データベース・ステータス・設定の4タブ
- 武器・体・追加・特殊・装飾スロット
- 装備選択モーダル
- 装備解除・全解除
- 条件なし能力の合計表示
- アイテムIDを使った共有URL生成
- `?build=...` から装備構成を自動復元
- 日本語を含むURLデータの安全なBase64URL化

## 更新方法

ZIPを解凍し、リポジトリへ中身をすべて上書きアップロードしてください。

コミット例：

```text
Update IrunaDB to v0.3.0
```
