# IrunaDB

Iruna Online Database & Build Simulator

## Version

`v0.9.0`

## v0.9.0 実装内容

- 各装備の精錬値 `+0～+10`
- 各装備のスロット数 `0～2`
- ダブルスロット対応
- スロット数に応じたクリスタ枠の有効・無効
- スロット数を減らした場合、無効になったクリスタを自動解除
- 武器属性の選択・上書き
- 精錬値、スロット数、ダブルスロット、武器属性を条件判定へ追加
- 全設定を共有URLへ保存・復元
- 設定変更時に合計能力と条件判定をリアルタイム更新
- v0.8.0までの装備・アルクリスタ・レリック機能を維持

## 対応する条件項目

- 精錬値 / REFINEMENT / REFINE
- 武器精錬 / 武器精錬値
- 体精錬 / 体精錬値
- 追加精錬 / 追加精錬値
- 特殊精錬 / 特殊精錬値
- 装飾精錬 / 装飾精錬値
- スロット数 / SLOT_COUNT
- 武器スロット / 武器スロット数
- 体スロット / 体スロット数
- 追加スロット / 追加スロット数
- 特殊スロット / 特殊スロット数
- 装飾スロット / 装飾スロット数
- ダブルスロット / DOUBLE_SLOT
- 武器属性 / 属性 / WEAPON_ATTRIBUTE

## 更新方法

ZIPを解凍し、GitHubリポジトリへ全ファイルを上書きしてください。

GASの変更は不要です。
