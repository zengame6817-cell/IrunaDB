# IrunaDB

Iruna Online Database & Build Simulator

## Version

`v0.2.0`

## v0.2.0 実装内容

- `ITEM_MASTER`連携
- `EFFECT_MASTER`連携
- `CONDITION_MASTER`連携
- `STAT_MASTER`連携
- `ATTRIBUTE_MASTER`連携
- 常時能力の表示
- 条件付き能力のグループ表示
- 属性IDを属性名へ変換
- 能力名・条件文を含む検索
- 複数APIの並列取得
